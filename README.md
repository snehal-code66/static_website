# 🌐 Host a Static Website with GitHub Pages

## 📌 Project Overview

This project demonstrates how to create and deploy a static website using GitHub Pages as part of my **Elevate Lab Internship – Task 6**.

## 🎯 Objective

To learn how to host a static HTML website for free using GitHub Pages.

## 🛠️ Tools & Technologies

* HTML5
* CSS3
* GitHub
* GitHub Pages

## ✨ Features

* Simple and attractive website design
* CSS styling and responsive viewport settings
* Publicly accessible website
* Free hosting using GitHub Pages

## 🚀 Deployment Steps

1. Created a new public GitHub repository.
2. Created an `index.html` file using HTML and CSS.
3. Committed the website code to the `main` branch.
4. Opened **Settings → Pages** in the repository.
5. Selected `main` as the deployment branch and `/(root)` as the folder.
6. Enabled GitHub Pages and waited for deployment.
7. Opened and verified the live website.
